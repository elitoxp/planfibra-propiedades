# CasaRey / propiedades.planfibra.cl

MVP inmobiliario para venta y arriendo de casas, departamentos, parcelas, terrenos y propiedades comerciales.

Incluye portada responsive, filtros por operación/tipo/comuna, avisos demo, favoritos de sesión, página para preparar publicaciones, SEO básico, sitemap, robots y páginas legales.

Los avisos demo están identificados y no representan propiedades reales.
